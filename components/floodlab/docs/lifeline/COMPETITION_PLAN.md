## Frozen comparison rules

1. Separate targets: **new open water**, **observed debris/landslide proxy**, and **terrain-inferred impact**.
   Mixed official event polygons are not automatically water labels. Report cross-class agreement as
   a diagnostic with its mismatch, never as water accuracy.
2. Freeze algorithms, thresholds, reference versions, AOIs and split roles before selection.
   Areas inspected during design remain development/diagnostic areas; do not relabel them untouched holdouts.
3. Use shared valid support for paired method scores, and additionally report full-AOI support/abstention.
   A small easy observed subset can otherwise inflate apparent performance.
4. Include the existing fixed-pair rule and simple terrain-only/no-change baselines. Add no-flood controls.
   Report counts, precision/recall/IoU/F1, undefined denominators, exposed infrastructure and missingness.
5. Compare model scores as scores. Closure priors, sigmoid outputs and Monte Carlo draw fractions are
   not calibrated real-world probabilities without independent calibration evidence.
6. A successful synthetic topology test proves the declared graph contract only. A deterministic
   replay proves saved-input calculations only. Neither proves field access, damaged buildings or safety.
7. Preserve raw inputs and frozen predictions. Store every evaluation outside frozen run directories.
   No threshold search against withheld labels. No source-data acquisition or retraining happened in this tranche.

## Stop rule

The current response work is closed before adding more horsepower. The next scientifically useful step
is to acquire and register suitable historical observations and matching evaluation support. It is not
to announce a detector win from the 729-graph routing result. If matched inputs are unavailable, report
`NOT ASSESSED` and retain this gap instead of manufacturing a benchmark.
