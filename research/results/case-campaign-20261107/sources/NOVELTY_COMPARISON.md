# SATQuery: closest prior work and bounded contribution

Checked 7 November 2026. This is a targeted comparison, not an exhaustive novelty search. Eight primary papers/frameworks are compared below. Relevant methods/evaluation sections were checked where accessible; the Narayan paper was available only through its indexed author-manuscript abstract. Lifeline's public README was accessible; nested source/raw/API retrieval failed, so its implementation and metrics remain author-reported and were not rerun. No app code was changed.

**Finding:** The broad combination of terrain, flood/change maps, exposed assets, network effects and natural-language assistance has clear antecedents. A first-ever claim is unsupported. A narrower contribution could be a tested evidence contract and reproducible evaluation of terrain-conditioned screening across declared mountain and urban case windows. **Exposure advantage, causal validity, calibrated risk and broad transfer are NOT VERIFIED.**

The campaign handoff supplies the implementation premise: established Priority-Flood/D8/HAND operations, SAR/optical change candidates, historical OSM and ordinal graph screening. This note does not independently audit that current code. Prior SATQuery audit context also cautions that deterministic routing and reproducible saved-input arithmetic must be distinguished from runtime LLM reasoning and independent scientific validation; those historical findings require current rechecking.

## Defensible candidate contribution

Candidate research question: **Does an explicit, reproducible evidence contract reduce unsupported exposure statements and make terrain-conditioned screening easier to audit, without an unacceptable loss of valid answers, across specified mountain and urban tasks?** This is a hypothesis to test, not a measured result.

A bounded contribution statement, conditional on completed evidence: “We implement and evaluate a reproducible change-to-exposure screening workflow that separates observed change, terrain-derived connectivity, receptor intersection and unsupported consequence claims. A typed evidence record preserves source epoch, spatial support, algorithm settings and reasons for abstention. Controlled tests assess numerical reproducibility and claim support on specified mountain and urban case windows.”

This is strongest as an **application/evaluation and software contribution** unless an independently measured improvement or new inference method is established. Cross-case execution alone demonstrates execution over those windows. It does not establish broad generalization. In particular, annual urban land-cover change and a mountain flood/debris event have different target classes and reference requirements; they must not be pooled into one “accuracy.”

## Minimum evidence needed before stronger claims

1. **Freeze the comparison before scoring.** Use the same inputs, valid masks, historical receptor inventory and reference roles for a change-mask intersection baseline, terrain screening and typed-graph/abstention variants. Separate development areas/events from held-out evaluation. Previously inspected Nepal reference areas stay development evidence.
2. **Test exposure against a suitable independent target.** Flood extent labels can assess flood extent; they do not automatically label building damage, road closure or isolation. Without compatible asset/access labels, report model-conditional counts/lengths and reference absence. Report precision/recall or error denominators by case and class where scoring is eligible; retain no-flood controls and mask/DEM sensitivity.
3. **Measure missingness and selective answering.** Declare observed, invalid/unobserved, absent source and unavailable target separately. Report answered fraction, error among answered cases, false-confident answers and false abstentions. Unknown OSM coverage is not “no assets.” A missing DEM/drainage route must not silently become a low-risk result.
4. **Test the evidence graph as a contract.** Each reported quantity needs source identity/epoch, units, grid/CRS/support, derivation settings and a trace to the frozen output. Keep observation, model inference and consequence distinct. Ordinal screening scores are not probabilities. Inject missing inputs, incompatible epochs/classes and contradictory evidence; record expected abstentions and actual outcomes.
5. **Evaluate the NL interface independently.** Use fixed factual, spatial, paraphrased and unsupported questions; score exact numbers/units, geometry/date selection, evidence correctness and unsupported inferences. A deterministic/template path is a valid baseline. If no runtime LLM participates, report deterministic NL routing. Software tracing tests establish contract behavior, not flood truth or analyst productivity.

**Stop rule:** If independent exposure targets remain absent, close the campaign with measured reproducibility, declared source coverage, sensitivity and evidence-contract results. Do not manufacture an exposure-accuracy claim or start adding a hydraulic/agentic subsystem to rescue the novelty story.

## Remaining limits of this review

- Targeted eight-work coverage cannot establish absence of similar work. Search coverage is intentionally bounded and includes papers, a standard and author-reported software; these have different evidence status.
- No comparator implementation was run and no SATQuery advantage was measured. Lifeline's moving README needs a commit-pinned code/data audit before a reproducible head-to-head claim. Its labels and reported outputs should not be copied into SATQuery as ground truth.
- The Narayan full manuscript fetch was blocked; only its indexed primary abstract supports the row. Other rows use accessible author text or the official standard. No papers or large data/model files were downloaded.
- Historical memory used for scope boundaries: `MEMORY.md` lines 525–527 and 540 (audit rollout `01a1907d-18b4-7473-8a6f-45e10a62ba87`). These are prior-audit context, not current campaign verification.
